# Becra Project Documentation

## Overview

This repository contains the Becra software platform and related services.

The project consists of:

- React / Next.js frontend
- Backend API routes
- MariaDB databases
- Railway deployment infrastructure
- Docker local development environments
- Android mobile integration support

## Main Technologies

| Technology | Purpose |
|---|---|
| React | Frontend user interface |
| Next.js | Frontend and backend framework |
| Node.js | Backend runtime |
| MariaDB | Database storage |
| Prisma | ORM layer |
| Railway | Hosting and deployment |
| Docker | Local environments |
| GitHub | Version control |
